# AMAYNO — Brand Store Amlou Maroc 2026

L'amlou authentique du Souss, livré chez toi partout au Maroc.

## Stack
- Next.js 14 (App Router)
- TypeScript + Tailwind CSS
- DTC avec paiement à la livraison (COD)

## Développement
```bash
npm install
npm run dev
```

## Déploiement EasyPanel
```bash
npm run build

```
